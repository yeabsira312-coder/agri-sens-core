# AgriSens Core – Satellite Agricultural Data & Thermal Anomaly Analytics

## Overview
AgriSens Core provides tools for analyzing crop health and vegetation stress using satellite‑derived climate datasets. It computes vegetation indices such as NDVI and detects localized temperature anomalies to help identify early signs of drought or heat stress.

## Key Features
- **Crop health tracking** – Monitor vegetation stress with NDVI and related indices.
- **Thermal anomaly detection** – Spot localized temperature spikes that may indicate drought or heat stress.
- **Interactive analysis** – Use Python, Pandas, and Matplotlib for data exploration and visualisation.

## Tech Stack
- Python 3
- Pandas
- NumPy
- Matplotlib
- SciPy

## Getting Started
```bash
# Clone the repository
git clone https://github.com/Yeabsera-Gezahegn/agri-sens-core.git
cd agri-sens-core

# Set up a virtual environment (optional but recommended)
python -m venv .venv
# On Windows
.venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the main analysis script (example)
python src/main_analysis.py
```

For more detailed usage, see the scripts in the `src/` directory.
